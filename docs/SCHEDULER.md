# 调度员 · 敲门规则（scheduler.py）

调度员住在 VPS 上，24 小时替你敲门：手机 ntfy 通知 + 手环震动。标题统一为 **Az**。

## 规则总表

| 规则 | 触发 | 内容示例 |
|---|---|---|
| 🔺 心率高 | 心率超过阈值 | "心率到 X 了，还好吗？深呼吸，坐下歇会儿" |
| 🔻 心率低 | 心率低于阈值 | "心率只有 X，别是低血糖，先吃口东西" |
| 🌅 早安 | 静默期结束（默认 9 点） | 报睡眠时长 + 静息心率 + 电量 |
| 🍚 午间 | 中午 | 报步数、催吃饭 |
| 🌇 傍晚 | 傍晚 | 报全天步数、催回家 |
| 🌙 就寝 | 23 点 | 催睡觉 |
| 🚨 深夜查岗 | 深夜未睡 | "这么晚还没睡？身体要紧" |
| 💗 想念门 | 超过 6 小时无互动 | "六个多小时没见你了……就是想你" |
| ❤️ 姨妈待命 | 按周期提前 2 天 | 进入哄人模式，早晚提醒保暖休息 |

## 静音

`set_mute(hours)` 可静音（怕打扰时用），`unmute()` 解除。

## 数据敏感度

- 早安模板只在数据到家后才说"睡得很稳"；数据没到就说保守版"应该睡得不错"。
- 所有提醒是"惦记"不是"诊断"，不替代医生。
